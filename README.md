# Basis

Market and business analytics that run in the browser. Part of my portfolio site.

## What it does

**Markets**

- Real daily closing prices for Apple, Microsoft, Nvidia, Alphabet, Amazon, Meta and Tesla, with the Nasdaq-100 ETF (QQQ) as the benchmark
- 20-day and 50-day moving averages, Bollinger bands and RSI
- Return, annualized volatility, maximum drawdown, return per unit of risk and beta
- A compare view that rebases two to four names to 100
- A correlation grid of daily returns
- A short written read of the numbers, produced by rules

**Business**

- Drop in a sales or orders CSV. It finds the date, the measure and the categories on its own.
- Monthly trend with a straight-line projection, a breakdown by category and a day-of-week pattern
- Written takeaways, each with the formula behind it

## How it is built

Plain HTML, CSS and JavaScript. No frameworks, no chart library and no build step.

- `index.html` is the page and its interface code
- `lab-core.js` holds the statistics, the CSV parser and the SVG charts
- `tech-data.js` is a saved price history from Yahoo Finance (November 13, 2026)

To run it, open `index.html` in a browser.

## Notes

- The stock prices are a saved snapshot. On my site the page also tries to refresh them through a small proxy rule; here it shows the snapshot.
- The "Simulated" tab uses made-up companies generated by a seeded random model.
- The takeaways are rule-based. No language model is involved.
- Uploaded files are read in the browser and never sent anywhere.
- This describes data. It is not investment advice.
